An exploratory analysis of World Bank Consumer Price Index (CPI) data
covering Pakistan, India, Bangladesh, Sri Lanka, and Nepal from

high-inflation periods, country-level differences, inflation volatility,

**Key Analysis:**

- Year-over-year inflation calculation
- Inflation trend analysis
- Average inflation comparison
- Inflation volatility
- Identification of high-inflation years
- Pakistan-focused analysis
- Cross-country comparison
- Correlation analysis
- Economic interpretation

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook
