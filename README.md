### 📊 Inflation Trend Analysis: Pakistan & Selected South Asian Countries

An exploratory analysis of World Bank Consumer Price Index (CPI) data covering Pakistan, India, Bangladesh, Sri Lanka, and Nepal from **2000–2025**.

The project focuses primarily on Pakistan and examines inflation trends, high-inflation periods, country-level differences, inflation volatility, and relationships between inflation rates.

**Key Analysis:**

* CPI data cleaning and transformation
* Year-over-year inflation calculation
* Inflation trend analysis
* Average inflation comparison
* Inflation volatility
* Identification of high-inflation years
* Pakistan-focused analysis
* Cross-country comparison
* Correlation analysis
* Economic interpretation

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook
