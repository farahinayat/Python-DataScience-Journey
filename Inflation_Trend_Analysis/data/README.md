# Dataset

The dataset used in this project was obtained from the World Bank.

## Indicator

**Consumer Price Index (2010 = 100)**

**Indicator Code:** `FP.CPI.TOTL`

## Countries

- Pakistan
- India
- Bangladesh
- Sri Lanka
- Nepal

## Period

2000–2025

## Notes

The original World Bank dataset contains annual CPI values.

Annual inflation rates were calculated in Python using the year-over-year
percentage change in CPI.
